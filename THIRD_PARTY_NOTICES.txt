Third-party notices for pr-cycle

The original concept comes from YuShen (@YuShenLiu06)'s yushen-skills project:
https://github.com/YuShenLiu06/yushen-skills.git
This repository builds on that work to implement the PR cycle workflow,
Claude Code integration and Kanban batch tooling as an independent project.
The original MIT copyright notice is retained in LICENSE.

External runtimes are downloaded separately and are not distributed in this
repository. The root MIT license does not relicense these external works:

- Anthropic claude-plugins-official / ralph-loop 1.0.1, pinned to commit
  f8c5e7a1dcb71b10cb74586224b5401f3de5db28. The setup script retains the
  upstream checkout, including its original notices and license files.
- BloopAI/vibe-kanban 0.0.166, pinned to commit
  0c91b082357972dbcfd79c93ab8d899b78181f1a, licensed under Apache-2.0.
  The optional local frontend build applies the tracked kanban-ui patch and
  replaces the commercial message-list component. The backend is unmodified.
  The source license and a modification notice are retained in the build.
- react-virtuoso, under MIT, resolved by the pinned upstream pnpm lockfile.
  The local frontend includes its license as REACT-VIRTUOSO-LICENSE.txt.
  This is the open-source virtualizer, not @virtuoso.dev/message-list.
- jq, obtained from its official release with a pinned SHA-256 checksum.
  Its upstream notices and applicable license continue to apply.
- Claude Code, installed and authenticated separately by the user, under
  its own service terms and license.

Runtime versions and download checksums are recorded in
skills/pr-cycle/assets/claude-runtime.lock.json and runtime.lock.json.
